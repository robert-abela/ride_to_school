YOUR RUNWAY — STANDALONE VERSION

To run:
1. Extract the ZIP file.
2. Keep index.html, styles.css and app.js in the same folder.
3. Double-click index.html.

No installation, web server, Node.js or internet connection is required.

Files:
- index.html: page structure and links to the other two files
- styles.css: all styling and animation
- app.js: choices, page behaviour and runway simulation
